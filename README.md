# Cleo

WhatsApp campaign assistant for **Aliu Johnson Temitope**, candidate for President, Patrician Set of 2012 (St. Patrick's College, Iwaro-Oka). See `replit.md` for behaviour, setup and deployment.

Quick start on Replit:

1. Tools > Secrets: add `GROQ_API_KEY` and `NVIDIA_API_KEY`.
2. Run the API Server and web workflows.
3. Open the dashboard and scan the QR code from WhatsApp > Linked devices.
4. In the group, say "Hello Cleo" or tag her.
